The things one machine cannot do.

A second person approving a call. One policy across a fleet. A budget that spans every agent rather than every laptop. None of it changes what the gate decides — and none of it is required to run one.

The line is one question.

Can one machine do this? If yes, it is Apache-2.0 and free forever. That is not a slogan — it decides every case. Enforcement runs on one machine, so blocking is free. A second person approving a call does not, so it is not.

Every paid item below is a hole SCOPE.md already documents, or work that only exists because more than one person did it. We are not inventing limitations to sell past.

Free — Apache-2.0, today

  • The engine, all fifteen seams, observe and enforce
  • Every resolver, and the record chain
  • init · inventory · report · propose · verify · prove · score
  • The console, every screen
  • Budgets over a session, a day, a week or a rolling window
  • No telemetry, no phone-home, no licence check

Cloud — coming soon

  • A second human approving a confirm
  • One org policy, signed and pinned by digest
  • Budgets pooled across the fleet, not per laptop
  • Audit across every agent, anchored in one place
  • The reviewed detection catalogue

Paying adds no availability risk to enforcement. A control plane can only ever make a decision more permissive, and only through a named human. Unreachable, absent or unpaid behaves exactly as a free install. That is a test in the repository, not a promise on a page.

And the client is already open. src/neti/cloud.py is Apache-2.0 and shipped, with the tests that pin every property a grant may have: bound to one call, single-use, expiring, and refused if the target has grown since a human looked at it. Read the protocol, write your own server, hold it to those tests. What the hosted tier sells is a server that is running.

Until then, the gate is complete.

There is no reduced mode, no trial and no watermark on the numbers. A single developer, or a team sharing a policy file in git, never needs any of the above. 

# everything one machine can do, which is the whole free tier
pip install "neti[all]"
neti start
